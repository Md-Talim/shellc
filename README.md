# shellc

A mini POSIX shell in C, built for the CodeCrafters shell challenge.

## Requirements

- CMake ≥ 3.13
- C23-capable compiler
- GNU readline dev headers (`libreadline-dev` on Debian/Ubuntu, `readline` on Homebrew)

## Run

```sh
./shellc.sh
```

Compiles via CMake and launches the interactive shell.
